# 猫猫记账

运行在 Windows 和 Mac 上的个人记账软件（Electron + Vue 3）。

## 怎么启动（开发时）

1. 安装工具包（第一次做一次即可）：`npm install`（本项目依赖安装方式见 CLAUDE.md 注意事项5）
2. 启动软件：`npm run dev`
3. 屏幕上会弹出"猫猫记账"窗口

## 怎么打包（发布用）

1. 执行：`npm run build`
2. 完成后得到 `release/猫猫记账-0.1.0-便携版.exe`——单文件免安装，双击即用，可拷给任何 Windows 电脑
3. Mac 版打包见 [Mac打包说明.md](./Mac打包说明.md)
